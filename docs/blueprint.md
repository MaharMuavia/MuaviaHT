# **App Name**: VisualCore Sentinel

## Core Features:

- Intelligent Signal Uploader: Streamlined interface for uploading business reports, spreadsheets, and screenshots for autonomous processing.
- Neural Agent Monitor: Hero visualization showing the live status, confidence, and reasoning progress of the Input, Insight, Impact, Decision, Execution, and Reflection agents.
- Reasoned Insight Scoring: Dashboard presenting business anomalies with AI-assigned severity levels and confidence scores.
- Autonomous Decision Engine: Strategic planning tool that analyzes multiple business recovery paths and autonomously selects the most effective execution strategy based on risk evaluation.
- Simulated Action Logs: Real-time terminal view detailing simulated AI executions like CRM updates, notifications, and workflow adjustments.
- Strategic Outcome Analytics: Interactive metrics visualization comparing business state Before vs After autonomous agent intervention.
- Intelligence Operations Archive: Persistent history stored in Firestore for auditing past analysis cycles and evaluating AI recovery trajectories.

## Style Guidelines:

- The visual scheme utilizes a high-tech dark mode. The primary color is a vivid Intelligent Blue (#4285F4) symbolizing reliability and insight. The background is a sophisticated desaturated Navy (#0F1116), while the accent is a bright Cyan-Blue (#2BB5FF) to highlight active agentic states and calls to action.
- A font pairing designed for tech clarity: 'Space Grotesk' for bold, machined-style headlines and 'Inter' for neutral, highly legible body text and terminal logs.
- Monolinear icons with subtle outer glows to indicate agent status (idle, thinking, active).
- A focused mobile-first vertical stack using high-radius glassmorphism cards and minimal margins for a clean, startup-inspired command center feel.
- Smooth workflow transitions and pulsing 'active state' effects on agent cards to illustrate live reasoning.
